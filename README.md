# code-harness

Reusable engineering skills and verification workflows for coding agents.

## Install

```bash
npx skills add Johnny-zbb/code-harness
```

## Skills

### pstack

Engineering principles for coding agents.

Focus areas:

- Build the Lever
- Prove It Works
- Encode Lessons in Structure
- Sequence Work into Verifiable Units

### create-verification-skill

Create a project-local verification harness that can launch, drive, observe, and capture evidence for real user workflows.

### maintain-verification-skill

Maintain verification coverage as projects evolve. Detect stale feature maps, missing drivers, and harness gaps.

### software-design-philosophy

Apply ideas from John Ousterhout's *A Philosophy of Software Design* when designing, refactoring, or reviewing code. Emphasizes deep modules, information hiding, design alternatives, simple interfaces, and meaningful—not narrational—code comments.

- [Skill](skills/software-design-philosophy/SKILL.md)
- [Optional project AGENTS.md rules](skills/software-design-philosophy/references/AGENTS.example.md)
- [Illustrative Agent lifecycle refactor](skills/software-design-philosophy/references/next-console-example.md)

Invoke for meaningful architectural or module-boundary work; small edits do not require a design ceremony.

## Philosophy

A coding agent should not only write code.

It should build the tools that prove the code works, and structure the code to minimize long-term complexity.
