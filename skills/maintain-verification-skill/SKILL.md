# Maintain Verification Skill

Use when a project already has a verification harness.

## Audit areas

Check:

- Feature Map accuracy
- Driver coverage
- Evidence quality
- Broken workflows
- Missing user paths

## Harness gap

When a user-visible workflow changes and the existing verification surface cannot prove it:

1. Identify the missing capability.
2. Add the smallest driver required.
3. Re-run the workflow.
4. Preserve evidence.

Do not replace project-specific verification details with generic checks.
